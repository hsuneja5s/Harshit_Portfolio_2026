Astha.ai: turning AI hesitation into banking self-service

Designing a secure, transaction-capable visual banking cockpit that redirects high-touch inquiries and bypasses prompt anxiety for private wealth clients.

Designed for a leading private banking platform, this project established the conversational interface and visual cockpit infrastructure that allows high-net-worth clients to query, execute, and authorize complex financial transactions. To address prompt anxiety and compliance-locked operational risks, the system maps rigid transactional boundaries—separating automated actions from safe human-in-the-loop escalation gates. The core design architecture utilizes a dual guided panel structure: an active conversational prompt stream side-by-side with a real-time visual transaction cockpit, shifting the user interaction from opaque text queries to high-trust interactive validation cards. This secure intent mapping and structured refusal matrix consolidated fragmented banking services and successfully boosted customer satisfaction metrics, driving NPS from 7 to 9.2 while reducing support call overhead by 34%.

Due to banking regulations, security compliance requirements, and national financial infrastructure rules, all interface designs, conversational datasets, and operational system flows are completely confidential.
