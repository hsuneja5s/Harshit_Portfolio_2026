PwC × Research Assistant

A PwC engagement plugin that generates editable information architectures, persona cards, user journey maps, and wireframe starters on canvas directly from raw PRDs.

StackFigma Plugin API · Claude Opus · Anthropic SDK

In brief

  • Uploads product requirement documents directly to scaffold editable personas, flows, and canvas maps in minutes.
  • Transforms low-signal document reading into instant, fully editable Figma-native layout components.
  • Employs an adversarial review pass to surface hidden system gaps and contradictions before team reviews.

Why I built it

Kickstarting enterprise engagements typically demands days of reading dense PRDs and manual layout alignment before real design work begins. I built this assistant to automate low-signal synthesis, mapping raw product requirements directly into structured research and diagram layers on the canvas so designers can focus purely on strategic judgments.

How it works

  • PRD Ingestion: Grounded parsing engine extracts core user intents, system boundaries, and functional scopes automatically.
  • Canvas Scaffolding: Renders information architectures, detailed persona cards, and flow maps instantly as fully editable Figma elements.
  • Devil's Advocate Mode: Performs a secondary adversarial pass to highlight hidden system gaps and design contradictions as prominent overlay notes.

Stack

  • Figma Plugin API to generate editable typography and vector-aligned frames directly on the canvas.
  • Claude Opus via Anthropic SDK to handle complex narrative synthesis and adversarial review audits.
  • Custom Layout Engine to organize generated outputs cleanly across a modular, structured spatial grid.

What I tried first

  • Interactive Wizards: Step-by-step interview flows placed excessive cognitive load on designers compared to simple, automated PRD ingestion.
  • Slide Presentations: Generating static client decks proved redundant since designers still had to manually translate those slides into native Figma frames.
  • Single-Output Engines: Restricting scope to simple information architectures fell short; the real speed gains required scaffolding the entire user research layer.
