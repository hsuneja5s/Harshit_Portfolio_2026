PwC × Research Assistant

A PwC engagement plugin that generates editable information architectures, persona cards, user journey maps, and wireframe starters on canvas directly from raw PRDs.

I built this plugin during my engagement at PwC to solve the tedious translation loop between text documents and design assets. By dropping a raw Product Requirement Document (PRD) directly onto the canvas, the tool parses core user intents and functional scopes to instantly scaffold fully editable information architectures, persona cards, user journey maps, and wireframe starters in minutes. It also runs a built-in adversarial review pass ("Devil's Advocate Mode") that contextually flags hidden system gaps and contradictions on canvas, helping teams identify missing requirements before high-stakes reviews.
