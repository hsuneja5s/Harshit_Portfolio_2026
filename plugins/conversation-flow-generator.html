Conversation Flow Generatordraft

A Figma plugin that drafts conversational UX flows and branch variants inside Figma from plain-English prompts, powered by Anthropic's models.

StatusBeta · used on global energy platform + national citizen-services platform conversational projects
StackFigma Plugin API · TypeScript · Anthropic SDK · Claude 4.6
BuiltQ1 2025 — alongside national citizen-services platform multilingual work
SourceClosed during PwC engagement · open-source release planned

In brief

  • Type the user goal ("file an FIR for a missing person") → plugin generates a complete flow with branches, error states, and fallback paths.
  • Localises into multiple languages from a single source. Hindi, Marathi, English, more.
  • Uses Anthropic's models with strict output schemas — fast iteration on conversational design without hand-drafting hundreds of variants.

Why I built it

During large citizen-service launches, voice-first flows had to be deployed across six regional Indian languages. Hand-drafting localized flow variants and conversational branch loops would have taken weeks. I designed this plugin to help designers author, localize, and test complete multi-turn conversational patterns natively in Figma, placing prompt register control directly where the visual interface lives.

How it works

  • Goal-First Scaffolding: Maps out branching paths, error recovery steps, and fallback loops from simple plain-language statements.
  • Figma-Native Generation: Renders dialogue trees as canvas frames using existing design system component layers.
  • Nuanced Localization: Translates conversation trees with culturally aware tone matching rather than literal word mappings.
  • Intent Variation: Auto-generates multiple user phrasing variants to simplify training models.

Stack

  • Figma Plugin API for frame and text canvas creation.
  • Anthropic Structured Tool-Use schemas for reliable flow mapping.
  • Claude 4.6 for dialect-accurate regional translation.
  • TypeScript enforcing a strict tree schema.

What I tried first

  • Spreadsheet Diagrams: Translating Google Sheets into canvas graphics felt slower than drafting components manually.
  • Engineering Prompts: Relocating prompt authorship to code repository files distanced designers from vital tone registers.
  • Free-Form Outflow: Generating without schemas created inconsistent visual conventions that hindered engineering handoffs.
