Design System Validator

A Figma plugin that runs comprehensive system checks to catch token mismatches, off-grid spacing, undocumented variants, and structural layout breaks before handoff.

As design files scale across multiple product teams, manual design system audits quickly become a bottleneck. I built this deterministic linter to automatically audit active Figma frames, flagging token mismatches, detached components, off-grid spacing, and auto-layout breaks directly on the canvas before the files are handed off to engineering. By suggesting inline, one-click remediations to swap deviations back to approved tokens, the plugin saved substantial engineering review cycles and cut handoff defects in PR reviews by roughly forty percent.
