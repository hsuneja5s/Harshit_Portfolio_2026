Design System Validatordraft

A Figma plugin that runs comprehensive system checks to catch token mismatches, off-grid spacing, undocumented variants, and structural layout breaks before handoff.

In brief

  • Scans active Figma frames instantly to flag non-system colors, radii, spacing, and broken auto-layout structures.
  • Replaces manual Notion checklists with a single-click audit that surfaces issues directly on canvas.
  • Catching errors before handoff saved engineering review cycles and reduced PR-level rework loops.

Why I built it

Managing over 120 components across multiple active designers demonstrated that manual design system audits simply do not scale. Because catching token deviations in code is ten times more expensive than resolving them inside Figma, I built an automated pre-handoff validator to ensure absolute layout and token compliance before files reach engineering.

How it works

  • Pre-Handoff Linter: Evaluates published component bounds and detects hardcoded layout properties automatically.
  • Inline Remediations: Suggests the closest semantic design system token to replace off-grid spacing or colors in a single click.
  • Structured Severity: Utilizes errors and warnings to flag structural breaks and guide designers without blocking active velocity.

Stack

  • Figma Plugin API for high-speed direct node tree traversal.
  • TypeScript Rule Engine to evaluate custom validation rules deterministically.
  • Deterministic Schema to ensure fast, reliable, and predictable system validation.

What I tried first

  • Manual checklists in Notion faced extremely low adoption; converting guidelines into a single-click native utility achieved near-100% team usage.
  • AI-based scans were far too slow for active design workflows and yielded probabilistic, untrustworthy suggestions instead of deterministic rules.
  • Hard blocking exports created bypass workarounds; shifting to structured, visible warning tiers guided behavior constructively.
