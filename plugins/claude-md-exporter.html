CLAUDE.md Exporterdraft

A Figma plugin that exports your design system as a single CLAUDE.md file, ensuring Claude Code generates components inside your exact tokens, naming, and rules.

StatusBeta · used internally on private-sector bank + national citizen-services platform
StackFigma Plugin API · TypeScript · Anthropic SDK
BuiltQ4 2025 — alongside private-sector bank engagement
SourceClosed during PwC engagement · open-source release planned

In brief

  • Pick your design system file in Figma → click Export → get a complete CLAUDE.md with tokens, components, naming rules.
  • Drop the file into your repo, and Claude Code generates inside your system instead of inventing its own.
  • Closes the gap between Figma's design system and Claude Code's component generation.

Why I built it

During large bank integrations, developers using Claude Code frequently scaffolded components with invented token names and off-grid spacing. I built this plugin to compile raw Figma tokens, naming standards, and component boundaries into a unified system context file that Claude reads natively, closing the design-to-code gap without manual prompt curation.

How it works

  • Token Compilation: Traverses variable collections and styles to map a semantic token tree.
  • Metadata Extraction: Extracts component specs, properties, and layout structures directly from page metadata.
  • Rule Alignment: Translates designer guidelines into plain-language constraints for Claude Code.
  • Context Optimization: Generates a clean, compact CLAUDE.md file tailored for LLM context windows.

Stack

  • Figma Plugin API for variables and component traversal.
  • TypeScript for layout compilation safety.
  • Markdown Templates optimized for Claude's context window.

What I tried first

  • Hand-Maintained Prompts: Manual rules went out of sync within weeks as design patterns evolved.
  • JSON Exports: Code assistants struggled to parse raw data trees without human-language context.
  • Token Packages: Solved stylesheet sync but left natural-language design intent completely undocumented.
