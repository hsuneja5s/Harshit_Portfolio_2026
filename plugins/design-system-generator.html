Design System Generatordraft

A Figma plugin that scaffolds complete design system foundations — including semantic tokens, key core components, and starting frames — in minutes.

StatusAlpha · piloted with internal-tools team at private-sector bank
StackFigma Plugin API · TypeScript · Anthropic SDK · Tokens Studio sync
BuiltQ3 2025 — alongside healthcare diagnostics provider system work
SourceClosed during PwC engagement · public release planned

In brief

  • Input one brand color + a few choices (typography scale, density, motion preference) → get a complete design system foundation in Figma.
  • Generates ~40 starter components, semantic token architecture, and 5 sample screens you can fork.
  • Built so internal-tools teams can spin up a system in a day instead of waiting six weeks for design system support.

Why I built it

Design system teams in large enterprises are often bottlenecked by manual requests. Since eighty percent of every internal system shares identical scaffolding primitives, I built this generator to scaffold semantic tokens, spacing frameworks, and primary components in minutes, leaving designers to focus purely on the custom, brand-differentiating details.

How it works

  • WCAG Contrast Mapping: Generates clean, accessible semantic color scales from a single brand color input.
  • Typography and Spacing: Adapts variables automatically based on density prompts (compact, comfortable, spacious).
  • Variables Generation: Configures a full token set as native, pipeline-ready Figma Variables.
  • Component Scaffolding: Deploys approximately forty core components with pre-configured responsive states.

Stack

  • Figma Plugin API for canvas variable creation.
  • TypeScript for component compilation safety.
  • Anthropic SDK for contextual variable suggestions.
  • WCAG Math Libraries for color compliance auditing.

What I tried first

  • Figma Starter Kits: Duplicated files were immediately modified in ways that broke downstream variable connections.
  • Spreadsheet Inputs: Text-heavy parameter grids presented a high cognitive barrier that hindered rapid adoption.
  • Unguarded Modifications: Unrestricted post-generation edits broke semantic mappings, resolved via a frozen foundation model.
